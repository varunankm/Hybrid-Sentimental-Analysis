📋 Expected file formats
  • CSV / Excel — column named review, text, content, feedback, or comment. Titles and short label cells are skipped automatically.
  • TXT — one review per line. Blank lines, headers, and single-word labels are ignored.
  • JSON — array of strings ["great app","needs work"] or array of objects [{"review":"..."},...]
  • PDF — text is extracted from every page. Only sentence-like content (3+ words) is kept; titles, page numbers, and column headers are filtered out.
💡 The smart content filter automatically removes titles, column headers, short labels, URLs, and numbers — keeping only real review sentences regardless of the file format.
